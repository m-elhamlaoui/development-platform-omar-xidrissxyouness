

## Overview
**Space Forces** is an online competitive quiz platform designed for space enthusiasts, inspired by **Codeforces**. It provides an engaging way for users to test and improve their knowledge of space-related topics through **timed quizzes, problem difficulty divisions, rankings, and curated quizzes**.

## Key Features

### 1. Quizzes
- Regularly hosted **space-themed quizzes**.
- Users compete in real-time, answering questions within a set timeframe.
- Problems categorized by difficulty (Beginner, Intermediate, Advanced).

### 2. Quiz Setters
- Users or experts can create and submit quizzes.
- Review process to ensure quality and accuracy.

### 3. Ranking System
- Users ranked based on **quiz performance**.
- Leaderboards updated per division (e.g., **Novice, Expert, Master**).
- Points assigned based on problem difficulty and accuracy.

### 4. Topic-based Challenges
- Quizzes categorized into **Astronomy, Space Missions, Rockets, Black Holes, Astrobiology, etc...**
- Users can choose to specialize in specific topics.

### 5. Space news
- Keep users updated with the latest space discoveries and events.
